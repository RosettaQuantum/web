Two things this table does not say. Each row's speedup is what the cited source declares, not a measurement of ours: declaring is not measuring. How to check this page

Everything above comes from the same database that answers the API. Download the source, recompute its sha256 and compare it with the one declared by /v1/algorithms under procedencia.instantanea_sha256: if it matches, you are looking at the same catalogue we are. Agents read it over the API or over MCP with buscar_algoritmo_cuantico.
